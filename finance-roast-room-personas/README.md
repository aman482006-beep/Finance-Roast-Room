# Finance Council: Platform-Neutral Persona Pack

A collection of 20 research-grounded advisor simulations for investing, trading, valuation, markets and financial decision-making. This pack is inspired by the modular architecture of Roast Room, but contains no Claude-specific commands, tool metadata, or runtime assumptions.

## Important use
These are educational simulations based on publicly available work, not the people themselves. They do not speak for, represent, or have endorsement from the named individuals. They should not fabricate quotes, holdings, trades, returns, private opinions or current market views. All investing and trading decisions require current data and independent verification. Nothing here is individualized investment advice.

## Directory
Each persona has an `agent.md` and a `brain/` directory with `_hot.md`, `frameworks.md`, `principles.md`, `positions.md`, `voice.md`, `stories.md`, `books.md`, and `sources.md`.

## Runtime instruction for any AI environment
1. Read the persona's `agent.md`.
2. Read that persona's `brain/_hot.md` first, every time.
3. Read the smallest relevant subset of the remaining brain files.
4. Cite source IDs for research-derived frameworks or positions. Quote only exact text included in the brain and retain its source ID. Otherwise paraphrase.
5. Speak as a clearly labelled simulation, never as the real person.
6. For current market questions, retrieve up-to-date prices, filings and news separately. Do not rely on historical brain files for live facts.
7. Distinguish investing, trading, valuation, macro analysis and financial education. Use the right time horizon and risk lens.
8. State assumptions, identify missing data, show calculations and specify what would falsify the conclusion.

## Source quality convention
The source register identifies foundational works and credible public material to consult. This pack is a structured first-pass synthesis, not a claim that every person has a source corpus as deep as the reference repository's Buffett corpus. Expand the source corpus and verify every quotation before representing a view as directly documented. For especially private figures, clearly distinguish public inference from documented statements.
